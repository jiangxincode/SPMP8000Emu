# Embedded Tone Library

`tonelib.bin` is the 130,500-byte SPMP8000 PCM tone bank used by the firmware's
NativeGE MIDI playback path. The emulator embeds it at compile time so MIDI
resources use the same melodic patches and percussion samples as the original
device.
